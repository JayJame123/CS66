# CS66 — ทำเนียบรุ่นวิทยาการคอมพิวเตอร์

เว็บไซต์ภาษาไทยสำหรับ CS66 มหาวิทยาลัยราชภัฏสกลนคร ใช้ Next.js, TypeScript, Tailwind CSS, Framer Motion และ Lucide

## เปิดใช้งาน

ต้องมี Node.js 22.13 ขึ้นไป

```sh
npm install
npm run dev
```

เปิด http://127.0.0.1:3000 สำหรับพัฒนา หากต้องการเปิดฉบับพร้อมใช้งาน ให้หยุดเซิร์ฟเวอร์พัฒนาก่อน แล้วรัน:

```sh
npm run build
npm start
```

ไฟล์สำหรับนำขึ้นโฮสต์อยู่ใน `out/` คำสั่ง `npm start` เปิดเฉพาะเครื่องนี้และรองรับหน้าโปรไฟล์โดยตรง

## แก้ไขข้อมูล

- `data/members.ts` — สมาชิกตัวอย่าง 6 คน บทบาท คำคม ทักษะ และลิงก์ติดต่อ ใส่รูปจริงใน `public/members/` แล้วกำหนด `image` เช่น `/members/jame.jpg` ไม่ได้เดาชื่อบุคคลจากภาพกิจกรรม
- `data/memories.ts` — ภาพกิจกรรมจริงทั้งหมด 196 ภาพ พร้อมชื่อและคำบรรยาย แบ่ง 4 อัลบั้ม
- `public/memories/` — ภาพกิจกรรมจริง 196 ภาพสำหรับใช้งานบนเว็บ
- `components/memories-gallery.tsx` — แกลเลอรีภาพ 4 อัลบั้ม พร้อมระบบอัปโหลดภาพกิจกรรมใหม่ และดูภาพเต็มจอ
- `components/upload-memory-modal.tsx` — หน้าต่างอัปโหลดภาพกิจกรรมใหม่สำหรับเพื่อนๆ
- `app/globals.css` — สี ฟอนต์ และการจัดวางจอคอมพิวเตอร์/มือถือ

หลังแก้ข้อมูลให้รัน `npm run build` ใหม่ก่อนใช้ฉบับพร้อมใช้งาน

## ขอบเขตปัจจุบัน

ใช้ภาพกิจกรรมจริงจากโฟลเดอร์ที่เจ้าของเว็บให้มา คัด 24 ภาพจากทั้งหมด 196 ไฟล์ ส่วนข้อมูลสมาชิกและข้อความฝากถึงเพื่อนยังเป็นตัวอย่าง ไม่มีระบบล็อกอิน อัปโหลด หรือโพสต์ข้อความร่วมกันออนไลน์ จำนวนโปรเจกต์เว้นไว้รอข้อมูลจริง

บันทึกเฉพาะธีมที่เลือกไว้ในเบราว์เซอร์ คลิกโลโก้ CS66 ห้าครั้งเพื่อเปิดเทอร์มินัลลับ รูปภาพโหลดจากเว็บโดยตรง ส่วน Google Fonts ต้องใช้อินเทอร์เน็ตและมีฟอนต์ระบบสำรอง
